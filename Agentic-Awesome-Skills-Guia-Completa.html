⚡ 1. ¿Qué es AAS Core?

Agentic Awesome Skills (AAS) es la biblioteca de código abierto más grande del mundo con más de 2,474 habilidades (SKILL.md) e instrucciones reutilizables para agentes de IA (Google Antigravity, Claude Code, OpenAI Codex, OpenCode, Cursor, Windsurf y Roo Code).

Permite a los desarrolladores dotar a sus asistentes de IA de estándares senior, arquitecturas comprobadas y flujos de trabajo especializados sin necesidad de escribir prompts manuales extensos.

⚡ 2. Comandos de Instalación CLI

BASH 
# 1. Buscar skills en el catálogo
npx -y agentic-awesome-skills@latest search "flutter"

# 2. Instalar una skill para Antigravity o Claude Code
npx -y agentic-awesome-skills@latest install ui-ux-pro-max --target antigravity

# 3. Instalación universal vía Skills.sh
npx -y skills add sickn33/agentic-awesome-skills -g -y

# 4. Inspeccionar el plan de skills antes de aplicar
npx -y agentic-awesome-skills@latest plan --stack react,tailwind,supabase

# 🚀 Mi Skill Experta

## 1. Cuándo activar esta Skill
- Cuando el usuario solicite arquitecturas de aplicaciones móviles o web.
- Antes de generar código en entornos de producción.

## 2. Reglas de Ejecución Obligatorias
1. Utiliza siempre tipado estricto con TypeScript.
2. Aplica arquitecturas modulares (Separation of Concerns).
3. No uses librerías deprecadas ni patrones no deterministas.
