---

## 📦 Cómo Instalar las Skills Oficiales de Anthropic

```bash
# Instalar todo el repositorio oficial de Anthropic
npx -y skills add anthropics/skills -g -y

# O instalar una habilidad específica (ej: mcp-builder, docx, xlsx, frontend-design)
npx -y skills add anthropics/skills/mcp-builder -g -y
npx -y skills add anthropics/skills/docx -g -y
npx -y skills add anthropics/skills/xlsx -g -y
npx -y skills add anthropics/skills/webapp-testing -g -y
```
