## 📦 Cómo Instalar Cualquier Skill en tu Entorno

Puedes instalar cualquier template en Claude Code o Antigravity con un solo comando en la terminal:

```bash
# Instalación directa vía claude-code-templates
npx claude-code-templates add <skill-path>

# O instalación global vía Skills.sh
npx -y skills add <skill-name> -g -y
```
